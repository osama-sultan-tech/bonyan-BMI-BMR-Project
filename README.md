# BMI & BMR Calculator (Bonyan - Task 01)

## Overview

### My First Step in Backend Development with Bonyan 🚀

I’m excited to share my first project from the **Laravel Internship Training** with **Bonyan**: a comprehensive calculator for Body Mass Index (BMI) and Basal Metabolic Rate (BMR).

This project focuses on transforming health-related mathematical formulas into an accurate and interactive digital tool. The goal wasn’t just to perform calculations, but to build a web application that combines the precision of backend processing with the fluidity of the frontend interface.


### Key Features of the Project:

🔹Accurate Calculations: Rely on PHP programming equations to process the entered health data.

🔹Modern User Experience: Tailwind CSS was used to ensure a responsive and visually appealing design.

🔹Real-Time Interaction: JavaScript was integrated to improve interface responsiveness and the user experience.

### Tech Stack
- Language: **PHP**
- Frontend: **Tailwindcss**, **JavaScript**
